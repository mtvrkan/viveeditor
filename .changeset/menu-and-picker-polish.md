Menus show the current item with accent text and a check mark, and keyboard focus as one inset ring. Headings 1, 2 and 3 have their own icons. The text colour, highlight and table colour panels have a built-in colour picker (colour area, hue slider, colour code, and an eyedropper where the browser has one) instead of the browser's colour window, start from the current colour, and work with touch and the keyboard. The `colorHue` and `colorEyedropper` message keys are new.
