The table panel has two tabs. "Cell" sets horizontal and vertical alignment, the cell colour (palette or any colour code) and the row, column, merge and header actions. "Table" sets width, alignment, borders, striped rows, border colour, equal column widths, column width and deletes the table. The panel stays open while you work, so you can change several things in one go.
