New toolbar controls: a font family menu that shows each font in its own face, a line height menu (single, 1.15, 1.5, double) and a list style panel for the bullet shape, the numbering type and the start number. The link panel can make a link open in a new tab, the image panel can link an image, and the code block Copy button is translated. The CDN build now also loads the font size panel.
Opening a Word file from the File menu passes the editor's font family list to the reader.
