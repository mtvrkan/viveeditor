Word export and import carry the new formatting: cell alignment, full-width and centred tables, row-only or no borders, border colour, striped rows, line height, font families (new `fontFamilies` import option), numbered list types and start numbers, bullet styles, links that open in a new tab and linked images.
Images read from a Word file no longer bring an empty paragraph with them.
