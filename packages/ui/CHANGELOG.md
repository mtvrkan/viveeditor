# @viveeditor/ui

## 1.0.0-rc.0

### Minor Changes

- 96ea657: New `CleanDocument` extension (part of `formatExtensions`) with the `cleanDocument` command and the `documentCleanup` query: it removes spaces at paragraph edges, repeated spaces, line breaks at paragraph ends and extra empty paragraphs in one transaction, never touching code blocks, and reports `{ extraSpaces, trailingBreaks, emptyParagraphs }`. The File menu gets "Tidy up document", which shows the counts in a notice.
- 96ea657: New `ClearFormatting` extension (part of `formatExtensions`) with the `clearFormatting` command and Ctrl/⌘+\: removes every mark except those in `keepMarks` (default `['link']`) from the selection and resets `blockAttributes` (default `['textAlign']`) on the selected text blocks; with a collapsed cursor it clears the stored marks. The toolbar and the selection bubble get a "Clear formatting" button.
- 9f59c19: Right-clicking a table, image, link, code block, video or formula opens a menu with the actions for that object, with submenus for cell, row and column actions. Plain text keeps the browser's own menu so spelling suggestions stay; Shift+right-click always shows the browser menu, Shift+F10 or the menu key opens it from the keyboard, and touch devices are left alone. The new `contextMenu` UI option (`'objects'`, `'always'` or `false`) controls it. Menus support submenus. Core gains the `selectAt` command and ext-embed the `selectedEmbedUrl` query.
- 9f59c19: The text colour and highlight panels take any colour: a system colour picker, a colour code field (`#1a73e8`, `1a73e8`, `rgb()`, `hsl()` or a colour name, checked before it is applied) and a row of recent colours that also lists the colours already used in the document.
- 96ea657: Document tools and drafts. `@viveeditor/core` adds the queries `findNodes(names)` and `findMarks(names)`, which return `FoundItem { name, attrs, text, from, to }` in document order (at most 2000). `@viveeditor/ui` adds outline, accessibility check, keyboard shortcut list (Alt+0) and full screen to the toolbar, the `exclude` option to leave tools out, and autosave: `createAutosave(editor, options)` or `autosave` on `createUI` keeps a draft under `viveeditor:draft:<key>`, shows a bar to restore or delete it, and can call your own `save` function; `EditorUI` gains `autosave`. `messages` also accepts the new `DocumentMessages` keys. The panel kit exports `createOutlinePanel`, `createCheckPanel`, `createShortcutsPanel` and `documentMessages`. `viveeditor` reads `data-autosave="key"` on a textarea and clears the draft after a submit, and its panels add-on now carries the special characters panel and the new panels.
- 9f59c19: Font size can be set in points. `setFontSize` takes a point value from 6 to 96 in half points (the old size steps still work), `stepFontSize` moves through the usual sizes from 8 to 72 pt, and the new `fontSizePoints` query reads the current size. The toolbar gets a font size control that shows the current size and opens a panel where you can type a size, step it up or down, pick a common size or go back to the default. Word export and import keep point sizes. The five size items left the text style menu, so the `fontTiny`, `fontSmall`, `fontNormal`, `fontBig` and `fontHuge` message keys are gone.
- 9f59c19: New toolbar controls: a font family menu that shows each font in its own face, a line height menu (single, 1.15, 1.5, double) and a list style panel for the bullet shape, the numbering type and the start number. The link panel can make a link open in a new tab, the image panel can link an image, and the code block Copy button is translated. The CDN build now also loads the font size panel.
  Opening a Word file from the File menu passes the editor's font family list to the reader.
- 96ea657: New `FormatPainter` extension (part of `formatExtensions`) with `copyFormat`, `applyFormat`, `cancelFormat` and the `isPaintingFormat` query: copied marks are applied to the next mouse selection, or to a Shift-arrow selection when Shift is released, and Escape cancels; links in the target stay. The toolbar gets a "Format painter" button, `ToolSpec` gains `activeQuery`, and the core stylesheet shows a copy cursor while painting.
- bd7fb9c: Selected images get four corner handles with a live size badge. Dragging a corner keeps the aspect ratio, stays between 16 px and the content width, and saves whole-pixel `width` and `height` in one undo step; double-clicking a handle returns to the natural size. Touch targets are 44 px and only the handles stop scrolling. The new `resizable` option turns the handles off, and the new `resizeImage`, `resetImageSize` and `replaceImage` commands and the `imageReplaceMode` query are available in code. The image panel adds width and height fields with "Keep aspect ratio" and "Reset size", and a "Crop" button that also sits in the image's right-click menu. The crop dialog, loaded with the other panels, offers Free, 1:1, 4:3, 16:9 and Original presets, works with mouse, touch and keyboard, and sends the cropped file through the `upload` function or embeds it when `allowBase64` is on. Cross-origin images without CORS show an explanation instead of failing.
- 96ea657: Image captions and positions, table cell colour and vertical alignment. `@viveeditor/ext-image` gives the image node `caption` and `align` (`'left' | 'center' | 'right'`, exported as `ImageAlign`), set through `setImageAttributes` and returned by `selectedImage`; an image with either is written as `<figure data-align><img><figcaption>`, one with neither stays a plain `<img>`. `@viveeditor/ext-table` gives cells `background` and `verticalAlign` with `setCellBackground`, `setCellVerticalAlign` and `query.cellStyle()`. `@viveeditor/core` now exports `normalizeColor` (still re-exported by `@viveeditor/ext-format`, whose highlight no longer picks up a cell background). The interface adds caption and position to the image panel and cell colour and vertical alignment to the table panel. `@viveeditor/sanitize` keeps `figure` with a checked `data-align`, `figcaption` and the two cell styles; its profile gains `imageAlign` and `verticalAlign`. Both sanitizers now also drop fully transparent `hsl()` and `hsla()` colours. `@viveeditor/docx` writes and reads cell shading and vertical alignment and writes captions as Caption paragraphs; `@viveeditor/markdown` writes a caption as an italic line under the image.
  
  `getJSON()` now writes `caption: null, align: null` on every image and `background: null, verticalAlign: null` on every table cell. Documents from 0.1.0 load unchanged and their HTML and Markdown output is identical, but code that compares `getJSON()` output with a stored object must allow the new attributes.
- bd7fb9c: The "More tools" menu is sorted into categories named after the toolbar groups (Text, Format, Lists and quotes, Insert, Paragraph, Links and search, Document). A category with three or more hidden tools opens as a submenu; one or two hidden tools are listed directly under the category name. Tools that own a menu, such as line spacing, alignment, text style, font and File, are a single row that opens their own submenu with the current choice checked, instead of spilling their items into the list without a label. On touch screens and where there is no room beside the menu, a submenu replaces the list and offers a back row; on desktop it opens beside the menu.
- 96ea657: New `PasteOptions` extension (part of `formatExtensions`) remembers the last formatted paste and adds `pasteAs('keep' | 'clean' | 'plain')`, `dismissPaste()` and the `lastPaste` query; switching restores the document from before the paste in the same transaction and re-runs the clipboard through the normal paste pipeline. The interface shows a paste options button next to the cursor after such a paste; Ctrl pressed on its own opens its menu and Escape hides it.
- 9f59c19: The table panel has two tabs. "Cell" sets horizontal and vertical alignment, the cell colour (palette or any colour code) and the row, column, merge and header actions. "Table" sets width, alignment, borders, striped rows, border colour, equal column widths, column width and deletes the table. The panel stays open while you work, so you can change several things in one go.
- 05a641f: Table rows get a height. Drag a row's bottom edge to set it (double-click the handle to reset), or use "Make row taller", "Make row shorter" and "Reset row height" in the table panel and the Row submenu of the context menu. New `setRowHeight` and `resizeRow` commands and a `rowHeight` query; the height is a minimum, saved as `<tr style="height: Npx">` (24 to 2000 px). Both sanitizers keep it within the new `maxRowHeight` limit, and Word files write and read it as an at-least row height.
- 15de121: Undo, redo and File always stay on the toolbar at laptop and tablet widths, while other tools move to the More menu in their fixed order. Below 560 pixels the toolbar also shows undo and redo; when a phone is too narrow, link moves to the More menu first, then redo, then undo. Link stays available in the selection toolbar.
- 96ea657: Writing tools. `@viveeditor/ext-format` adds `Subscript`, `Superscript`, `FontSize` (`FONT_SIZES`, `setFontSize`, `unsetFontSize`, `stepFontSize`), `Indent` (`indent`, `outdent`, `indentLevel`), `ChangeCase` (`changeCase`, `cycleCase`, language-aware) and `Typography` (smart quotes, dashes, ellipsis and symbols), all part of `formatExtensions`; `ClearFormatting` now also resets `indent`. `@viveeditor/core` exports `textInputRule`. The interface adds a "Text style" menu, indent items in the alignment menu and a lazy special characters panel. `@viveeditor/sanitize` keeps `<sub>`, plain `<sup>`, editor font sizes on `span` and indent on paragraphs and headings, and drops nested font sizes and nested superscript or subscript; its profile gains `fontSizes` and `indents`. `@viveeditor/docx` maps superscript and subscript to `w:vertAlign`.
  
  `getJSON()` now writes `indent: null` on every paragraph and heading. Documents from 0.1.0 load unchanged, but code that compares `getJSON()` output with a stored object must allow the new attribute.

### Patch Changes

- e8c82d0: Core hooks for comments, track changes and collaboration. An extension can set `replacesHistory: true` so the core history is left out and its own `undo` and `redo` commands are used (both answer false if it registers none). `transformTransaction(transaction, state, context)` lets an extension rewrite a local edit before it is applied, in priority order; it is skipped for remote and selection-only transactions, and a result built for another state is reported as `INVALID_TRANSACTION` and the original edit is kept. `isRemote(transaction)` and `REMOTE_META` mark edits from a peer or a sync, and the `change` event now carries `remote`. Autosave and the character limit ignore remote edits.
- bd7fb9c: Toolbar panels such as the link panel are no longer squeezed into a sliver near the screen edge, and they follow their button when the page scrolls or zooms.
- 96ea657: Fixes before 1.0. `@viveeditor/core` keeps leading, trailing and repeated spaces inside footnotes when the document is saved and loaded again. `@viveeditor/markdown` writes complete video links: the Vimeo private link part and the YouTube or Vimeo start time are kept. `@viveeditor/ui` applies the HTML typed in the source view before its form is submitted, also when a script calls `form.requestSubmit()`. `viveeditor`: `MountDestroyedError` is now a `ViveEditorError` with the code `DESTROYED`.
- 1a1a861: Menus show the current item with accent text and a check mark, and keyboard focus as one inset ring. Headings 1, 2 and 3 have their own icons. The text colour, highlight and table colour panels have a built-in colour picker (colour area, hue slider, colour code, and an eyedropper where the browser has one) instead of the browser's colour window, start from the current colour, and work with touch and the keyboard. The `colorHue` and `colorEyedropper` message keys are new.
- 9f59c19: Menus and panels no longer show a horizontal and a vertical scrollbar on systems that always show scrollbars: the gradient edge is now drawn inside the border instead of one pixel outside it. The code block language picker and the special character category picker share one look in every browser (same height, a drawn arrow, hover and focus ring) and keep the native picker on phones.
